## [0.1.0] — 2026-06-24

### Added
- Первый релиз. Локальный CLI-агент для программирования на базе GigaChat.
- Инструменты: чтение/запись/редактирование файлов, `list_dir`, `find_files`,
  `search_content`, `run_shell`, безопасное подмножество `git`.
- Агентный цикл с function calling, потоковый вывод (SSE), REPL и одноразовый режим.
- Слой безопасности: песочница по корню проекта, подтверждение опасных операций,
  классификация риска команд.
- Контекст проекта: дерево файлов + файл-память `DEVASSIST.md`.
- Терминальный UI на rich: диффы, панели, сводка по шагам/токенам.
- Тесты: офлайн-юниты, live-тесты GigaChat (маркер `live`), сквозной smoke-тест.
