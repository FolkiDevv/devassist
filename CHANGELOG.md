# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/lang/ru/).

## [Unreleased]

### Changed
- Проект переведён на [uv](https://docs.astral.sh/uv/): `uv.lock`, dev-зависимости
  в `[dependency-groups]`; `requirements*.txt` удалены.
- Реорганизация кода под дорожную карту (см. `docs/ANALYSIS.md`): пакеты
  `project/` (Workspace, обход файлов, инструкции) и `cli/` (REPL, реестр
  слеш-команд); ядро агента общается с UI через события `AgentEvents`;
  история диалога — сериализуемый `Conversation`; ограничители цикла — `LoopGuard`.
- `.env` больше не записывается в окружение процесса, а `GIGACHAT_*` удаляются из
  окружения запускаемых команд. Скрипты, которые полагались на наследование
  ключа дочерними процессами, должны получать его явно.
- История укладывается в бюджет контекста по оценке токенов
  (`DEVASSIST_CONTEXT_TOKENS`) вместо лимита в 80 сообщений.
- `read_file` отдаёт не более 1000 строк / 60 тыс. символов за вызов с подсказкой
  продолжения; диапазон строк работает для больших файлов.
- `list_dir` и дерево проекта показывают скрытые файлы (`.github`, `.gitignore`).
- В статистике хода раздельно показаны размер контекста и потраченные токены.
- Ctrl+C на приглашении REPL больше не завершает программу (выход — Ctrl+D или `/exit`).

### Added
- Чтение `DEVASSIST.local.md` (личные инструкции проекта).
- `docs/ANALYSIS.md` — анализ кодовой базы и дорожная карта.
- Переменная `DEVASSIST_CONTEXT_TOKENS`; коды возврата одноразового режима (130 при Ctrl+C).

### Fixed
- Падение REPL при записи/редактировании файла по пути вне проекта.
- Битая история после Ctrl+C во время работы инструмента.
- Дублирование текста ответа при обрыве соединения посреди потока.
- Падение REPL на сетевых ошибках, не обёрнутых в `GigaChatError`
  (`ReadError`, `ProxyError`, не-JSON ответ и др.).
- Недетерминированный приоритет `.env` проекта и текущей папки; traceback на
  некорректных `GIGACHAT_TIMEOUT`/`DEVASSIST_TEMPERATURE`.
- Выход за песочницу: `find_files` с `../`, `git diff --output=…`/`--no-index`,
  чтение файлов по симлинкам наружу в `search_content`.
- `git branch -D/-m` выполнялись без подтверждения; несуществующая подкоманда `stash-list`.
- Зависание команд, ожидающих ввод (`cat`, `git commit` без `-m`), и команд с
  фоновыми процессами; бинарный вывод команд; потеря конца длинного вывода.
- `search_content`/`find_files` обходили `node_modules` и т.п. целиком; читали
  бинарные и огромные файлы; `max_results` не ограничивался.
- Вывод ESC-последовательностей из ответа модели и вывода команд в терминал.
- Ложная классификация `rm <файл на r/f>` как опасной команды.

## [0.1.0] — 2026-06-24

### Added
- Первый релиз. Локальный CLI-агент для программирования на базе GigaChat.
- Инструменты: чтение/запись/редактирование файлов, `list_dir`, `find_files`,
  `search_content`, `run_shell`, безопасное подмножество `git`.
- Агентный цикл с function calling, потоковый вывод (SSE), REPL и одноразовый режим.
- Слой безопасности: песочница по корню проекта, подтверждение опасных операций,
  классификация риска команд.
- Контекст проекта: дерево файлов + файл-память `DEVASSIST.md`.
- Терминальный UI на rich: диффы, панели, сводка по шагам/токенам.
- Тесты: офлайн-юниты, live-тесты GigaChat (маркер `live`), сквозной smoke-тест.
